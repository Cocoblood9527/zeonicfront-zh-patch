# Zeonic Front 繁體中文漢化補丁

PS2《機動戰士鋼彈 0079：吉翁前線》日版繁體中文漢化 xdelta 補丁。

## 使用方法

需搭配日版原盤 `Zeonic Front - Kidou Senshi Gundam 0079 (Japan).iso`：

```sh
xdelta3 -d -s "Zeonic Front - Kidou Senshi Gundam 0079 (Japan).iso" zeonicfront-zh-patch-V20261123_1.xdelta "ZeonicFront-TC-V20261123.iso"
```

補丁檔案見 [Releases](https://github.com/Cocoblood9527/zeonicfront-zh-patch/releases)。
